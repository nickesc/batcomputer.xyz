A directory of apps, game tools, experiments, and APIs that live on [batcomputer.xyz](https://batcomputer.xyz). Built with SvelteKit.

## Run locally

Use Node.js 24 or newer.

```sh
npm ci
npm run dev
```

## Check and build

```sh
npm run check
npm run lint
npm run build
```
